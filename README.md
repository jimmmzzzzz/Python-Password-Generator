Python Password Generator

A simple command-line password generator built with Python.

The program allows users to generate customizable passwords and choose whether to include uppercase letters, numbers, and special characters. It also checks the strength of each generated password.

Features

- Choose password length
- Include uppercase letters
- Include numbers
- Include special characters
- Generate random passwords
- Password strength checker
- Generate multiple passwords without restarting the program
- Simple command-line interface

Technologies Used

- Python
- "random"
- "string"

How to Run

1. Clone or download this repository.

2. Open the project folder in your terminal.

3. Run:

python password_generator.py

4. Follow the prompts to customize your password.

Example

=== PASSWORD GENERATOR ===

Password length: 12
Include uppercase letters? (y/n): y
Include numbers? (y/n): y
Include symbols? (y/n): y

Generated Password:
A8#kL2!pQ7$m

Strength: Very Strong
